# ISO/IEC 27701 Sources and Scope

## Version snapshot

- Baseline document: `ISO/IEC 27701:2025`, Edition 2, published in 2025-10; the IEC product page lists the publication date as 2025-10-14.
- Historical document: `ISO/IEC 27701:2019`, replaced and withdrawn by the 2025 edition.

## Usage rules

1. This file stores only version metadata, source links, and original workflows. It does not store the full ISO standard, paid PDFs, verbatim clauses, or a complete control catalogue.
2. Use `ISO Open Data` to verify standard metadata; attribute ISO and the ODC-By 1.0 license when using it.
3. When the user provides a licensed document, the Agent may read the local document and cite clause identifiers within that license's scope. Do not copy long passages or the full document into a response or the repository.
4. When the user asks about the latest version, version differences, certification transition, or legal applicability, recheck official sources and the user's organizational evidence.
5. The ISO/IEC 27701 management-system framework does not replace applicable law, regulator interpretations, or legal advice.
