# 行動應用 App 基本資安檢測基準 V4.0 — 總覽、分類與更新同步規範

官方來源：[行動應用資安聯盟 App Q&A](https://www.mas.org.tw/app/questAndAnswer)  
目前整合版本：**行動應用 App 基本資安檢測基準 V4.0**（中華民國 113 年 9 月）

## 1. 適用範圍與基準性質

- 本檢測基準依據數位發展部數位產業署承接之《行動應用 App 基本資安規範 V1.5》「4. 技術要求」編訂，並參考 OWASP MASTG V1.7.0、OWASP MASVS V2.0、CSA MAST 及 NIST SP 800-163。
- 適用於非特定領域及規範中適用之行動應用程式（Android / iOS / 跨平台）。
- **重要界定**：通過本檢測基準代表使用者在**未破解作業系統層保護（如 Root、Jailbreak）**時，App 具備基本資安水準；基準包含「**檢測項目**（必要符合，共 49 個獨立檢測條目）」與「**參考項目**（`REF-1`～`REF-16`，僅供開發參考，不納入強制檢測）」。

## 2. 核心用語與定義精要（第 3 節）

| 用語 | 基準定義摘要 |
| :--- | :--- |
| **個人資料（3.3）** | 依個人資料保護法可直接或間接識別個人之資料（姓名、生日、身分證字號、護照號、指紋、病歷、聯絡方式、財務情況等）。 |
| **敏感性資料（3.4）** | 包含個人資料，並涵蓋密碼、金鑰、視訊、照片、通話、錄音檔、即時通訊、通話記錄、簡訊、備忘錄、通訊錄、筆記、地理位置、行事曆及**裝置識別符**（IMEI、MEID、IMSI、ICCID、MAC、Android ID、AID、iOS IFAID 等）。 |
| **交易資源（3.6）** | 涉及交易行為之有價值項目（實體貨幣、虛擬貨幣含點數/序號、票券含股票等）。 |
| **交易記錄（3.7）** | 交易對象、交易商品名稱、交易時間、交易金額、支付方式與交易狀態（完成/交易中/取消）。 |
| **預授權交易（3.8）** | 使用者事先給予特定目的交易許可權，未來多次連續交易無須再額外取得同意。 |
| **冗餘檔案（3.46）與設定檔（3.47）** | 冗餘檔案為與功能無關、刪除不影響再次執行表現之暫存/快取檔；若刪除造成自動登入失效，則屬設定檔而非冗餘檔案。 |
| **安全亂數產生函式（3.55）** | 符合 ANSI X9.17、FIPS 140-3、NIST SP 800-22 及 SP 800-90A (CAVP) 至少一項標準。 |
| **安全網域（3.56）** | 公共安全網域（如 Facebook、Google、Twitter）或行動應用資安聯盟白名單列表。 |
| **安全加密函式（3.57）** | 符合 FIPS 140-3 SP800-140C 所列加密函式，且**禁止使用 Triple DES (3DES/DES3)**（自 2023/12/31 起剔除）。 |
| **系統憑證儲存設施（3.58）** | 作業系統提供儲存憑證或金鑰之機制，如 Android Keystore、iOS Keychain。 |

### 發布狀態判定規則（第 4 節表 1）
1. **公開－已發布**：已於商店上架（須檢查商店內聲明與 App 內聲明）。
2. **公開－尚未發布**：開發階段未來預計上架（須於調查表填寫預計聲明與取得同意方式，且在 App 內實作聲明與同意）。
3. **不公開（企業內部）**：僅企業內部使用（無論是否透過內部商店發布），`4.1.1.1.2`、`4.1.1.1.3`、`4.1.1.3.1` 判定為「不適用」，但須「取得使用者同意」之項目（`4.1.2.1.1`、`4.1.2.3.1`、`4.1.2.5.1`）仍須於 App 內聲明及取得同意。

## 5. 檢測結果判定原則（第 7 節與程式碼靜態審核擴充）

- **符合要求**：程式碼與設定明確落實該項所有必檢基準，或滿足條文定義之「未蒐集／未儲存／未分享／未採用該機制」免除條件（並附檔案行號證據）。
- **不符合要求**：程式碼或設定明確違反任一必檢基準（須附 `path:line`、觸犯基準點與具體修補建議）。
- **不適用**：完全符合 V4.0 明文規定之不適用情境（如 iOS 之 `4.1.5.1.3` / `4.1.5.5.8`、不公開發布之發布聲明、無 Webview 之 `4.2.2.1.2`、非屬目標分類之項目）。
- **待人工／動態確認**：該項目依賴上架商店頁公開內容、實際執行期封包側錄、系統備份檢查、實際聯絡測試或網頁伺服器弱點掃描報告，單憑靜態程式碼無法最終定論。
